analyst-decoded stage-two scripts (each file named after a commit prefix), plus the current
archive and its decoded stage two. The mapping of the current archive to commit `4b6ea6b2`, and
all commit dates and times, come from the analysis note; no clone or commit JSON of the
delivery repository is retained (see the final list). Archive members were listed, never
extracted or opened. The archive password is redacted from every command.

### Claims without a retained primary artifact

- The delivery repository's creation in March 2026, and the four commit dates and times
  (5 March 06:17, 17 March 05:14, 25 March 03:54 and 13:29 UTC): no clone, bundle or commit JSON
  of the delivery repository is retained. The commit prefixes survive only in the file names,
  and the current archive's attribution to `4b6ea6b2` rests on the analysis note.
- Unavailability of the final PowerShell payloads (`bpvme.ps1`, `coks.ps1`) via unauthenticated
  routes, and the decision not to use recovered tokens: recorded only in the note.
- Account status (404 while the name stayed unavailable for registration), the suspension
  hypothesis and the adjacent-ID check: these were HTTP observations; no responses were saved.
- The decoded stage-two files are analyst derivations of the LNK command lines; the decoding was
  not re-run for this exhibit set (the shared key in E11-2 and the LNK size increase at
  b209f365, 420 KB to 429 KB, are consistent with them).
