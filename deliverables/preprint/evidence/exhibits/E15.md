## Exhibits

The companion repository is the authors' own code and is quoted directly. Its JavaScript unit
tests were rerun for this exhibit set (Exhibit E15-5): they run offline and their inputs are
inline strings that are only parsed. The Python detection tests were not rerun because
`yara-python` and pySigma are not installed in this environment, so their result is quoted from
the validation record. No held sample was executed. Its held inputs were only hashed.
